# A 方案细化与设置核对

2026-11-05。用户选定 A 的布局，要求增加深色、调整浅深色为莫兰迪撞色、按钮改直角、下载页严格按识别类型展示、逐项检查设置内容。本轮仍为设计预览，未改正式 Android 实现。

当前预览：`selected-a.html`。外层“媒体链接示例/普通文件示例/识别前”仅用于审稿，不属于产品内界面。产品内只有 URL、剪贴板、识别，以及识别成功后对应类型的选项。修改 URL 后旧选项立即失效，开始下载不可用，需重新识别。示例只识别两条指定 example.com 链接，不能冒充真实解析能力。

## 配色与组件

- 浅色：暖灰底 `#F3F0EB`、雾蓝绿 `#536F73`、灰玫瑰主操作 `#8B5860`。
- 深色：深蓝灰底 `#232C30`、低饱和灰绿 `#B0C8C5`、灰粉主操作 `#D7B2B7`。
- 所有按钮、选中标签、输入与下拉框采用直角；分组面板与手机硬件外框仍保留圆角。
- 外观三选一：浅色、深色、跟随系统；手动选择不被系统主题变化覆盖。正式实现复用现有主题模式持久化入口。

## 设置逐项核对

| 分类 | 具体内容 | 意义与处理 |
| --- | --- | --- |
| 外观 | 浅色、深色、跟随系统；配色样本与当前生效模式 | 删除无具体选项的“颜色方案”占位入口；这两版是同一套配对主题 |
| 下载行为 | 同时下载数量、文件重名策略 | 分别决定排队和覆盖冲突处理；属于本轮拟新增行为，未宣称现有 Android 已实现 |
| 下载行为 | 断点续传说明 | 基础要求默认启用，不提供误关恢复进度的开关；不支持续传或内容变化须重新确认 |
| 下载行为 | 媒体格式与字幕说明 | 引导回每次媒体识别结果中配置，普通文件不显示这些选项 |
| 网站与登录 | 网站选择、授权登录/退出、Cookies 文件引用 | 按域名生效；不引入含义不明的“隐私开关”；预览不收集账号或文件 |
| 通知 | 系统通知权限入口、完成提醒、失败提醒 | 权限交给 Android 系统；完成和失败偏好与权限分开 |
| 通知 | 前台服务通知说明 | 不提供无法保证生效的“关闭进行中通知”开关 |
| 存储与记录 | 默认目录、更改、恢复默认 | 真实目录授权入口，不只是显示一行路径 |
| 存储与记录 | 清理未完成下载缓存 | 必须先列出所属任务与空间，明确恢复点会丢失；不删除已完成文件 |
| 存储与记录 | 清除任务记录 | 默认不删文件；删除文件是独立且默认未选中的确认项 |
| 关于与组件 | 工程版本、解析器版本与手动检查更新、媒体处理能力 | 核对工程版本为 1.0.10；解析器运行时值不编造；能力说明不伪装成开关 |
| 使用与声明 | 本地数据与隐私、使用授权、第三方许可 | 均有详情；许可清单复用工程已有五项组件与真实来源链接，不新增无地址的政策入口 |

媒体选项仅在媒体结果显示；仅音频模式切换为音频格式并隐藏字幕。普通文件仅显示文件信息、可编辑完整名称、扩展名提示、续传能力、保存位置与重名处理。确认源文件身份与安全续传的技术要求继续沿用原交互提案。
