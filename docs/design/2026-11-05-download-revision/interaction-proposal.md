# Android 下载器修订：待确认交互方案

日期：2026-11-05。状态：候选设计，尚未批准开发，不取代既有权威设计与实现计划。

本轮用户要求先 Android、后 Windows。交付 `index.html` 交互设计稿与 A/B/C 三张三页面对照图。任务、链接、文件大小、权限状态与续传能力均为演示数据；图片预览取自原始参考图中的既有缩略图。浏览器原型检查不属于 Android 前台 GUI 验收。

## 三种视觉方向

- A 轻盈卡片：宽松圆角分组、填充式分段按钮、卡片任务、设置分类列表。偏重直观操作，是本轮推荐方向；相对同屏信息量较少。
- B 紧凑工作台：平直线框、横排标签表单、窄间距任务列表、设置分类就地展开。适合频繁批量管理；初次使用的亲和力较弱。
- C 留白编排：较大的页面标题、下划线输入、开放式任务分隔、双列设置入口、深色底部导航。视觉辨识度更强；设置分类下的细节需要进入查看。

三套方案独立改变控件形状、表单排列、任务容器、信息密度、标题层级、设置结构及导航选中方式。颜色不作为区分方案的依据。底部保留下载、格式、任务、历史、设置五入口，提议将原队列入口改名为任务；最终名称待用户确认。

## 统一链接入口

1. URL 框旁提供有可访问性名称的剪贴板按钮，仅用户点击时读取；不监听剪贴板。
2. 链接识别异步执行，可取消与重试；不阻塞启动或界面。不仅凭 URL 扩展名判断内容，结合 HTTP 响应信息、媒体解析结果判断。
3. 网站媒体或媒体直链展示预览、内容模式、可用格式、字幕与保存位置。格式页继续用于媒体详细选项；预览失败不阻塞下载。没有可用字幕的媒体不展示伪选项。
4. 普通 HTTP/HTTPS 文件直链展示文件名、类型、大小（不可得时显示未知）、保存位置和续传能力。网页、登录页与错误响应不能当成成功文件下载。此轮不推定支持磁力链接、BT 或网盘私有协议。
5. 设计稿中的媒体/普通文件切换用于比较两种结果状态；正式版默认依据识别结果呈现，不要求用户先判断类型。

## 普通文件名与保存

- 文件名优先取有效 Content-Disposition，其次取最终 URL 路径；缺少时使用明确的默认文件名。名称需去除非法字符与路径片段。
- 完整文件名可编辑。扩展名发生变化时立即显示行内提示：修改名称不会转换文件内容，并提供恢复原扩展名。正式提交时如扩展名仍不同，再要求确认一次。
- 文件名清空或包含无效字符时给出具体说明，不能提交。
- 保存位置使用 Android 系统目录选择；不能假设所有设备共享固定绝对路径。
- 重名默认自动编号；避免静默覆盖现有文件。

## 断点续传：本轮明确要求

- 普通文件支持暂停、继续、网络中断恢复、应用重启后恢复未完成任务。已下载字节、临时文件与源文件校验信息持久保存；不在界面或日志暴露含凭据的下载链接。
- “已暂停”保留进度，操作为继续；“失败”提供原因与重试；恢复原任务而非新增一条重复任务。
- 能力显示区分“待确认”“支持续传”“不支持续传”。不能只因 HEAD 或 Accept-Ranges 就承诺已经支持；实际范围响应与源文件一致性验证才是依据。
- 恢复时核对源文件身份（例如 ETag/Last-Modified、长度）并请求对应字节范围。服务端忽略范围请求、内容发生变化、续传文件丢失等情况不能盲目拼接；明确提示重新下载，由用户确认。
- 校验响应范围、总长度及完成状态，防止错误的 HTTP 200/206/416 被视为安全追加或成功。
- 取消与暂停分开：暂停保留恢复点；取消默认保留任务记录、清理未完成临时文件，允许重新下载。缓存清理如会删除恢复点，先明确列出受影响任务。
- 视频直链如果走普通 HTTP 传输，也复用可靠的续传机制；网站媒体仍遵循下载引擎实际能力，不承诺所有网站均可恢复。

## 全部任务与筛选

- 默认无筛选，展示进行中、等待中、已暂停、已完成、失败、已取消等所有任务。合并、写入等收尾阶段归入进行中，在行内显示实际阶段。
- 顶部一行横向滚动标签，包含全部、各状态、分隔符、视频、音频、其他文件。滚动时需保留可继续滑动的视觉提示，TalkBack 能读出分组和选中状态。
- 状态组可多选，类型组可多选。组内为或，组间为且。例：“进行中 + 失败”与“视频”表示进行中或失败的视频任务。
- 某组没有选项表示该组不限；再次点击已选项取消选择；全部清空两个组。筛选摘要始终可见，空结果提供清除筛选入口。计数按实际任务更新。
- 视频/音频按最终主输出分类；MP4、MP3 等媒体直链也应正确分类。字幕是媒体任务附件，不增加重复主任务；PDF/ZIP 等属于其他文件。
- 初始按创建时间倒序，恢复时更新原任务状态。演示稿为比较状态而固定顺序；正式排序规则可在开发方案中确认，不引入额外复杂排序控件。
- 进行中可暂停与取消，等待中可取消，暂停可继续，失败可重试，已完成可打开文件/目录，取消可重新下载。服务端不支持续传时不能用“继续”掩盖从头重下。
- 任务页覆盖完整任务生命周期，保留历史入口作为既有已完成文件检索入口。其冗余程度在最终导航确认时一并评估，本轮不擅自删除已有入口。

## 设置分类

| 分类 | 归入内容 |
| --- | --- |
| 外观 | 跟随系统/浅色/深色、现有配色选项、显示样式 |
| 下载与功能 | 并发数、断点续传行为、重名策略、媒体默认选项与处理能力 |
| 网站与隐私 | 按网站管理授权登录、Cookies 引用、清除会话 |
| 通知 | 系统权限入口、任务进度、完成提醒、失败提醒 |
| 数据与存储 | 默认目录、恢复默认路径、下载缓存、任务记录清理 |
| 关于 | 已安装版本、解析器版本与更新、项目帮助 |
| 声明 | 隐私政策、使用与授权说明、第三方开源许可证 |

尊重当前 Android 支持边界；此表是分类提案，不借整理设置扩展代理、云同步等功能。更新与权限动作由明确入口触发，启动不等待网络请求。
