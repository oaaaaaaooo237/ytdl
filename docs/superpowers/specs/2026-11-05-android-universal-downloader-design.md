# CaptainFlash Android 通用下载器修订（用户已批准）

日期：2026-11-05。用户已同意 `docs/design/2026-11-05-download-revision/selected-a.html` 的浅深色 A 方案并要求重构 APK；新增能力和原有能力都不得丢失。本文是本轮增量权威设计，取代旧设计的五页导航与配色规定；其他安全、媒体兼容、授权和验收约束继续有效。

## 交付与成功条件

生成可安装、可升级的 APK（保留 applicationId 和现有数据），包含 arm64-v8a 与 x86_64。版本提高到 1.1.0 / versionCode 12。不包含 Google Play 发布、商店素材或生产签名变更。正式生成的 APK、SHA256、安装验证和测试记录保存在项目 artifacts 与 docs/qa 下。

成功必须有：新旧核心行为单测、迁移/持久化测试、构建成功输出、可见模拟器前台 GUI 操作证据、APK 文件和校验。构建、adb 和 instrumentation 不能替代前台可视验收。Windows 不改动。

## UI 与导航

三入口：下载、任务、设置。采用用户批准的 A 纵向单页布局、莫兰迪撞色、直角按钮。浅色以暖灰底、雾蓝绿和灰玫瑰主操作为主；深色以深蓝灰底、灰绿与灰粉主操作配对。面板和手机外框的圆角不等于按钮圆角。保留系统浅深色跟随、手动模式、旋转和字体缩放安全区。

下载页中识别前没有类型相关选项；URL 改动后清空旧分析与选择，必须重新识别。主动点击剪贴板按钮读取，绝不后台监听。媒体识别结果展示预览、完整格式/字幕选择、保存位置和已有媒体功能，格式作为页面内展开区或子页而非主导航。普通文件只显示名称、类型、大小（未知时明确未知）、续传能力、保存位置、重名处理。媒体与普通文件选项不能混杂。

## 识别与普通文件

支持 HTTP/HTTPS 文件直链；保留所有已有 yt-dlp 网站分析路径。先用有界 HTTP 探测识别文件直链：响应 Content-Disposition、MIME、最终 URL 共同决定，HTML/登录页/错误响应不能保存为下载成功文件；媒体直链按媒体分类并进入合适下载路径；网站页面走原 yt-dlp。不能只凭 URL 扩展名分类。手动识别和所有网络工作后台执行，可取消/过期结果丢弃，启动不等待网络。

文件名优先合法 Content-Disposition filename* / filename，再用最终 URL 文件名，最后有明确默认名称。去除路径分量、控制字符与不合法名称；保留可用 Unicode。允许改完整名称；变更扩展名立即提示，提交仍不同需确认；空名称、无效名称不可开始。重名默认自动编号保留两个，不静默覆盖；询问策略只在真实冲突时触发。SAF 与应用私有路径继续支持。

## 安全断点续传

普通文件使用应用自己的 HTTP 流式下载器，不能假借 yt-dlp 支持来完成。持久保存临时文件和恢复所需 URL/身份信息；敏感 URL 不写明文日志或公开 Room 字段，复用加密恢复载荷。暂停、网络中断、进程重启后保留恢复点；继续原任务，不重复创建。

使用 Range 和 If-Range（强 ETag 优先，否则可用 Last-Modified）验证身份。只有匹配的 206、正确 Content-Range 起点/总量且身份一致时追加。200 忽略 Range、ETag/Last-Modified/总量改变、错误范围、临时文件缺失或元数据不一致时，不追加、不自动覆盖，显示需要重新下载并由用户明确确认。416 仅在已下载长度等于可信总量且身份验证一致时完成，否则拒绝。缺少可靠身份验证时不承诺安全续传。压缩编码必须固定 identity，避免字节偏移不一致。校验截断响应与声明长度，空文件作为合法文件时按实际定义处理，不能错误套用媒体必须非空的完成约束。

读写定期报告真实已下载字节、总量（可空）、速度和 ETA；无总量使用不确定进度，不编造百分比。取消清理临时文件并保留已取消记录；暂停保留临时文件。网络恢复遵循已有用户意图，主动暂停不能被自动恢复覆盖。源发生变化时提供明确重新下载确认。文件生成后复用已有导出链，不丢失私有副本/导出失败恢复语义。

## 统一任务

默认包含进行中（含合并/导出等阶段）、等待中、已暂停、已完成、失败、已取消。合并实时、排队、恢复和历史条目，以稳定任务 ID 去重；升级后旧任务与历史继续可见。进度、速度、ETA 和错误均来自真实状态。

顶部单行横向滚动标签包含全部、各状态、视频、音频、其他文件。状态组多选 OR，类型组多选 OR，跨组 AND，空组不限，全部清空。按最终主要输出分类，字幕作为附件。任务行具备当前状态可用动作，已有打开、导出、分享、删除、搜索/历史检索、重试、继续和取消能力保留。没有文件时不能显示可打开的成功。

## 设置

外观：浅/深/跟随系统；默认采用批准的莫兰迪配对主题。保留用户旧配色偏好的兼容迁移，不因删除一个旧入口导致读取失败。

下载行为：实际可用的并发设置、重名策略；续传是基础能力说明而非误关开关。不能提供没有接入调度的并发控件。

网站与登录：保留网站登录、登录状态判断、Cookies 按网站匹配/导入/清除/可读性检查和授权说明；引用与内容不得泄露。

通知：系统权限入口，完成/失败提醒偏好真正影响通知；运行前台服务通知按系统规则显示，不能用无效开关声称关闭。

存储与记录：默认目录选择、恢复默认、缓存统计与安全清理、任务记录清理。清理前明确恢复点影响，不默认删除完成文件。

关于与组件：实际安装版本、解析器状态/检查更新/安装/切换/回退等现有能力、媒体合并能力说明；保留可用帮助。声明：现有实际开源清单、使用授权、本地数据说明，无虚构政策 URL 或空点击项。

## 不得回归

媒体独立视频+音频合并、仅音频/仅视频/直出单文件、字幕语言/来源与独立文件、实际选中格式不静默回退、缩略图预览失败不阻塞下载、网站登录与 cookies、解析器独立更新与版本操作、任务持久化/暂停恢复/网络状态、历史/自动导出/打开/分享/文件删除、私有与 SAF 保存及权限失效恢复、通知、启动响应与隐私保护。以 `docs/qa/android-universal-downloader-retention.md` 的源码映射为准。当前没有内置播放器，不将设计稿里的播放图标当作现有播放器能力。本次按批准设计将已有字幕后端接到 GUI 选择，不因导航收敛删能力。

## 验收

先用真实 HTTP 服务覆盖范围响应、改变源、忽略范围、416、未知长度、截断、重定向、HTML 拒绝、文件名与重名，再回归媒体 pipeline。前台可见模拟器使用系统软键盘输入 URL，走识别、媒体配置、下载、暂停继续、任务筛选、完成/失败/取消、导出与设置。保留一个模拟器窗口并按项目规定摆放。真实媒体测试遵守已有网络节流，不对未授权内容测试。无法完成的检查必须逐项明确记录，不能据辅助测试标记目标完成。
