# 电脑版连续下载修复计划

按用户指定的 Android → Windows → Git → 旧包清理顺序执行。现有 GUI 设计和功能范围不变。

1. 解析结果复用：先用回归测试证明重复网页解析、会话和格式漂移问题；为 Pornhub 同域启用一致 TLS 配置，每个请求复制分析结果，通过 stdin 交给 yt-dlp，不写临时 info JSON。仅原 URL、Cookies 摘要相同且 15 分钟内复用；恢复队列不保存媒体地址。验证：新测试、子进程树测试、全量 pytest。
2. 删除门禁：移除全局下载互斥，保护当前任务已公布的目标文件；未确定文件名时只保护可能写入的输出目录。保留现有共享引用、硬链接、目录链接及文件身份校验。验证：无关历史可删除、活动文件和未知目标仍受保护。
3. 真实运行：同两个地址选择低分辨率，第一条下载中分析并入队第二条，验证自动接续和最终成品。打包后做启动和依赖 smoke，记录真实范围。
4. 两端代码、测试和 QA 文档提交并推送当前分支；最后仅清理旧版生成安装包，保留最新两端交付及用户文件。
