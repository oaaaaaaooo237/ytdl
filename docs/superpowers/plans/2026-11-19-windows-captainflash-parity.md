# CaptainFlash Windows 重做与功能对齐

对照 Android 1.11.10 标准版及 Torrent 变体，使用用户已选的 A 方案和 Windows 左侧三页，电驴沿用本机引擎。

1. 逐项核对安卓入口、实现、状态和现有验收。Windows 保留已有媒体、批量分析、任务恢复和电驴能力。
2. 补齐文件直链的识别、命名、重名策略、续传、并行连接、总限速和地址列表导入。嵌入浏览器与分站点登录，凭据使用 Windows 本地保护。接入种子文件和磁链的本机下载、文件选择及恢复。每个引擎单独验证，再进入统一任务与历史。
3. 接入可恢复的定时任务、等待上限、通知和任务跳转偏好。通过 Windows 任务计划程序在当前用户已登录时执行关窗后的预约。核对历史重下、复制链接、导出和分享、识别字幕、存储和清理、解析器管理，以及浅色、深色、跟随系统和配色切换。
4. 统一整个应用的版面。下载页在空态提供真实入口，识别后按媒体、文件、种子或电驴呈现对应操作。任务页用连续行呈现进度和可执行动作。设置首页展示分类与当前值，详情页承担配置。保留 Windows 原生窗口控件。
5. 打开最终便携包，按实际动作验证所有关键链路，记录包校验值、系统差异与仍有外部条件的样本。

## Windows 实机验收

- CaptainFlash 1.4.0 Win11 x64 便携 ZIP 的 SHA-256 为 `E54AD6A15AF6F67E7CD295BA51044336130C5A876919746E30117CC5471A0C32`。
- 从下载页识别普通文件和媒体直链，修改文件名、打开格式与字幕页、回到下载并核对成品。对支持强 ETag 和范围请求的样本观察四段传输并校验 SHA-256。
- 在内置浏览器保存样本站点会话，重新打开时确认会话恢复。把浏览器地址带回下载页，下载只有该会话可访问的文件并核对产物。
- 在磁链文件选择页确认选中文件，使用本机测试节点传输，核对两个成品的 SHA-256 和历史记录。公共电驴搜索返回实际结果，独立节点供应的 eD2k 文件从首页直贴、接收至历史记录，成品与原件一致。
- 在计划时间前关闭程序并确认原进程退出。到点后 Windows 启动预约，文件落盘校验通过，后台实例自行退出。预约使用当前用户的已登录会话。
- 分享操作使用 Windows 的复制和文件导出。当前界面语言为简体中文。
