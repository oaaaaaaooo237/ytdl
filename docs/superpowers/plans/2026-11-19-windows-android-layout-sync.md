# Windows 同步安卓版 A 布局

已确认同步布局、莫兰迪配色和直角控件，保留 Windows 左侧导航。参考 Android 1.11.10 的 Compose 布局和已选 A 方案的 `approved-a-tokens.json`。

1. 下载页按「地址与识别操作、识别结果、下载选项、保存位置、开始下载」排列。地址变更时使上一次识别结果失效。保留批量、格式与字幕、预览、电驴搜索和直链流程。验证识别前、识别结果、输入变更及 eD2k 四种状态。
2. 使用 A 方案的浅色配色和直角输入、按钮及选择控件。队列用分隔线呈现连续任务行，设置按使用目的分组。验证各左栏入口与当前任务及设置动作。
3. 在正常和最窄窗口检查内容、控件和滚动。用最终 Windows 便携包验证首页、任务、设置及原生关闭。
4. 左栏和 Android 一样采用「下载、任务、设置」三项。格式与字幕归入下载结果，全部历史归入任务，关于与组件归入设置。验证嵌套页面的返回和下载后跳转。

Windows 1.3.0 便携包实测了三个左栏入口、打开格式与字幕并返回、设置中的关于与组件、媒体识别直至下载落盘，以及任务中的全部历史。媒体成品与本机测试源的 SHA-256 一致。最后点击 Windows 原生关闭按钮并确认进程退出。
