# Android 1.0.1 Task Page and Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供稳定的下载速度/大小展示、合并后的任务页面、精简历史文案和 1.0.1 安装包。

**Architecture:** 保留现有下载状态、队列卡片和历史卡片，扩展 `RuntimeDownloadState` 保存速度与阶段内固定总大小，并由新的 `tasks` 路由组合运行中任务和历史记录。历史数据库结构不变，只调整 `HistoryUiItem.meta` 的前台映射。

**Tech Stack:** Kotlin、Jetpack Compose、Room、JUnit/Robolectric、Chaquopy、Gradle 9.4.1、Android API 37。
