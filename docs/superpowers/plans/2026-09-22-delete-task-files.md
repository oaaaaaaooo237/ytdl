# 删除任务时可选删除下载文件

> 使用 superpowers:subagent-driven-development；每个实现 Task 分配 fresh subagent，主会话复查并验证后继续下一 Task。

目标：PC 和 Android 的现有删除记录确认框增加默认不勾选的“同时删除下载文件”。用户已要求实现并在完全权限下完成测试。

设计：确认后，未勾选保留文件；勾选先校验文件归属，再删除确切关联的下载文件，成功后移除记录。缺失文件不阻止删除记录；路径异常、共享引用、文件仍在使用或删除失败保留记录并给出中文提示。不推测同名文件、不递归删除任意目录、不跟随符号链接或 junction。运行中任务须先停止；现有取消操作不自动变成文件删除。

## Task 1：PC 删除确认与精确文件删除

- 修改 `src/ytdl_gui/ui/main_window.py` 的历史单条删除、清空历史和清除已完成队列入口，复用独立确认框。
- 新增小型文件删除服务，按记录的完整输出路径删除普通文件；拒绝相对路径、目录、模板、链接及父路径链接，保护其他历史/运行任务引用的文件，删除失败保留记录。
- 回归测试覆盖默认不勾选、取消、成功删除、文件缺失、拒绝目录/链接/共享引用、删除失败保留记录、队列已完成清理。
- 先运行失败测试，再实现；全量 pytest 验证。保留上一轮单文件格式修复。

## Task 2：Android 删除确认与归属校验

- Android 基线：异步询问后按推荐的较新 1.0.3 工作树继续，目录 `.qa-data/worktrees/android-unknown-single-file-1.0.3`。用户后续明确授权按最新版本，同时实现 1.0.4 续传；见本日续传实施计划。
- 复用历史删除确认框，使用 Checkbox + 中文说明，打开每条记录均重置为未勾选。
- 基于数据库读取的真实记录和固定 App 私有下载根目录验证输出文件归属，拒绝非普通文件/符号链接/越界路径/其他任务共享引用。已经导出时只对记录的精确 SAF 文档 URI 删除，先检查非目录且不是树根；无权限时保留记录。独立复制的副本不从标题猜测或批量搜索删除。
- 若持久化数据不够证明文件归属，拒绝文件删除而保留记录；不得通过放宽路径规则补齐。
- 单元测试和 Compose 测试先失败后修复；Gradle 目标测试、全量测试、构建顺序执行。
