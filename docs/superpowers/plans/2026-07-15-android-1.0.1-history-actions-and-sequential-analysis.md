# Android 1.0.1 History Actions and Sequential Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成历史卡片紧凑布局、阻止旧地址结果覆盖当前地址、增加任务页动态滚动条，并完成 1.0.1 最终发布和四地址连续分析验收。

**Architecture:** 历史操作继续使用同一个 `FlowRow`，分析请求使用进程内递增编号隔离迟到结果。任务页给公共 `LazyColumn` 绑定当前页面独立的 `LazyListState`，仅在任务内容溢出时叠加与滚动位置同步的右侧滑块；下载页沿用同一可上下拖动列表，不增加常驻滚动条。

**Tech Stack:** Kotlin、Jetpack Compose、Robolectric Compose Test、Chaquopy、Gradle 9.4.1、Android API 37。

        onFailure = { error ->

- [ ] **Step 3: 实现最小滚动比例函数**

在 `YtdlApp.kt` 中加入：

```kotlin
internal data class LazyListScrollbarMetrics(
    val thumbFraction: Float,
    val offsetFraction: Float,
)

internal fun lazyListScrollbarMetricsForUiTest(
    totalItemsCount: Int,
    firstVisibleItemIndex: Int,
    firstVisibleItemScrollOffset: Int,
    averageVisibleItemExtent: Float,
    viewportSize: Int,
): LazyListScrollbarMetrics? = lazyListScrollbarMetrics(
    totalItemsCount,
    firstVisibleItemIndex,
    firstVisibleItemScrollOffset,
    averageVisibleItemExtent,
    viewportSize,
)

private fun lazyListScrollbarMetrics(
    totalItemsCount: Int,
    firstVisibleItemIndex: Int,
    firstVisibleItemScrollOffset: Int,
    averageVisibleItemExtent: Float,
    viewportSize: Int,
): LazyListScrollbarMetrics? {
    if (totalItemsCount <= 0 || averageVisibleItemExtent <= 0f || viewportSize <= 0) return null
    val estimatedContentSize = averageVisibleItemExtent * totalItemsCount
    if (estimatedContentSize <= viewportSize) return null
    val maximumScroll = estimatedContentSize - viewportSize
    val currentScroll = firstVisibleItemIndex * averageVisibleItemExtent + firstVisibleItemScrollOffset
    return LazyListScrollbarMetrics(
        thumbFraction = (viewportSize / estimatedContentSize).coerceIn(0f, 1f),
        offsetFraction = (currentScroll / maximumScroll).coerceIn(0f, 1f),
    )
}
```

- [ ] **Step 7: 绑定 `LazyListState` 并替换固定装饰条**

在 `key(selected.route)` 内创建 `val pageListState = rememberLazyListState()`，把它传给公共 `LazyColumn(state = pageListState)`。仅在 `selected.route == "tasks"` 时调用新的 `TaskListScrollIndicator(pageListState)`。组件以 `state.canScrollBackward || state.canScrollForward` 判断是否溢出，并用 `derivedStateOf` 调用 Step 3 的纯函数；轨道和滑块分别使用 `ytdl-tasks-scroll-indicator` 与 `ytdl-tasks-scroll-thumb` 标签。滑块最小高度为 `44.dp`，轨道位于页面右边缘且不遮挡任务卡片。

```kotlin
@Composable
private fun TaskListScrollIndicator(
    state: LazyListState,
    modifier: Modifier = Modifier,
) {
    val metrics by remember(state) {
        derivedStateOf {
            if (!state.canScrollBackward && !state.canScrollForward) {
                return@derivedStateOf null
            }
            val layoutInfo = state.layoutInfo
            val visibleItems = layoutInfo.visibleItemsInfo
            if (visibleItems.isEmpty()) return@derivedStateOf null
            val visibleSpan = visibleItems.last().offset + visibleItems.last().size - visibleItems.first().offset
            val averageExtent = visibleSpan.toFloat() / visibleItems.size
            val calculated = lazyListScrollbarMetrics(
                totalItemsCount = layoutInfo.totalItemsCount,
                firstVisibleItemIndex = state.firstVisibleItemIndex,
                firstVisibleItemScrollOffset = state.firstVisibleItemScrollOffset,
                averageVisibleItemExtent = averageExtent,
                viewportSize = layoutInfo.viewportEndOffset - layoutInfo.viewportStartOffset,
            ) ?: return@derivedStateOf null
            calculated.copy(
                offsetFraction = when {
                    !state.canScrollBackward -> 0f
                    !state.canScrollForward -> 1f
                    else -> calculated.offsetFraction
                },
            )
        }
    }
    val currentMetrics = metrics ?: return
    BoxWithConstraints(
        modifier = modifier
            .fillMaxHeight()
            .width(8.dp)
            .padding(vertical = 16.dp)
            .testTag("ytdl-tasks-scroll-indicator"),
    ) {
        val thumbHeight = (maxHeight * currentMetrics.thumbFraction)
            .coerceAtLeast(44.dp)
            .coerceAtMost(maxHeight)
        val travel = (maxHeight - thumbHeight).coerceAtLeast(0.dp)
        Box(
            Modifier
                .align(Alignment.Center)
                .fillMaxHeight()
                .width(3.dp)
                .clip(RoundedCornerShape(3.dp))
                .background(LocalYtdlAppPalette.current.borderColor),
        )
        Box(
            Modifier
                .align(Alignment.TopCenter)
                .offset(y = travel * currentMetrics.offsetFraction)
                .width(3.dp)
                .height(thumbHeight)
                .clip(RoundedCornerShape(3.dp))
                .background(LocalYtdlAppPalette.current.softText)
                .testTag("ytdl-tasks-scroll-thumb"),
        )
    }
}
```
