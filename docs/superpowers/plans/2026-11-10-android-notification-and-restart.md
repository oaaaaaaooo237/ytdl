# Android 下载通知与重启回归计划

用户要求：解析器更新后关闭重开保持选择；通知显示内容与真实进度，点击进入任务；下载后是否跳转由下载行为设置控制；在已连接手机用既有真实链接验收，尽量不抢电脑焦点。

沿用现有界面及设置，通知使用系统样式。跳转开关默认值保持 false，适用于媒体、普通文件及种子；通知点击独立于该开关。未知总量使用不确定进度，不编造百分比。已存在的解析器修复先回归，不重复修改。

## 用户追加的解析器列表设计

- 版本、来源（内置/已下载/未下载）、单选状态三列；底部两行四个等大图标：选择、删除；刷新、退出。保留删除确认和不可删除限制。
- 新版未下载行在版本号左侧标红“新”，右侧独立下载图标，不可单选。下载后转为普通单选行，仍需明确选择并确认；首页更新提示原有下载并选择行为保留。
- 修正异步启动后设置摘要停留在内置版本的问题；必须与详情页的实际版本一致。
- 目标测试覆盖四按钮大小/排列、单选暂存、禁用状态、新版下载到可选状态、下载不改变已有选择、异步加载摘要与晚到回调。
- Phone Use 已按用户要求停止安装。测试期间 USB 保持唤醒，结束恢复原值 0；使用 Agent Desktop，避免反复主动切电脑焦点。
