# 2026-11-03 Android 连续下载修复验收

## 最终实现

- Pornhub 分析和下载使用同一兼容 TLS 配置，保留证书校验；其他网站不改变网络方式。
- 成功分析后将可下载信息与会话 Cookie 快照保留在进程内存，以随机 analysisKey 传递给该任务。下载用 process_ie_result 对同一份格式列表执行用户选择，避免第二次打开网页造成空格式、连接重置或格式 ID 变化。
- 快照只在原地址和 Cookies 文件内容摘要一致时可复用，容量上限 16 条，可复用期限 15 分钟。过期清除在访问或容量淘汰时发生；没有写入磁盘缓存。恢复文件刻意不序列化 analysisKey，进程退出后恢复走正常重新解析。
- 等待卡片提供精确 taskId 的取消；当前任务及剩余顺序不受影响。取消清理失败进入不可继续的恢复项，不回到可执行队列。
- 下载期间允许删除无关联的 App 私有历史输出和无输出记录，仍校验任务归属、共享引用、链接和路径边界；外部 SAF 输出保留空闲门禁。
- No video formats 的具体中文原因在分析、下载和历史中保留，不再重复转换为文件处理失败。
