# Android 解析器、通知与下载跳转复测

## 本轮范围

用户报告解析器更新后冷启动仍提示更新；要求通知含内容、真实进度，点击进入任务；下载后跳转由设置控制。后续明确解析器管理采用版本/来源/单选列表和两行四图标按钮，新版行标红“新”并独立下载，下载后才可选择。

## 已确认原因与改动

- 真机 V2545A、Android 16、arm64，原安装 1.11.6/18 Torrent。旧版显示已选 2026.10.26，冷进程重开仍弹“发现新版解析器 2026.10.26”。旧版截图保存在 `artifacts/20261110/screenshots/01-old-parser-selected.png` 和 `02-old-restart-prompts.png`。
- 1.11.9/21 候选已同签名覆盖升级。详情页确认 Python 实际运行 2026.10.26；设置摘要仍显示启动瞬间的 2026.3.17。根因是摘要 remember 与 DisposableEffect 回调捕获旧运行版本。新增动态版本测试先失败、修复后通过。最终版本号提升至 1.11.10/22。
- 通知使用真实 percent、字节量、速度和 ETA，未知百分比显示不确定进度。通知 Intent 包含任务身份，MainActivity 冷/热启动均派发任务导航，处理后消费以避免 Activity 重建重复跳转。保留暂停、继续、取消与提醒偏好。
- 种子提交原先强制跳任务页，现与其他类型统一遵守 jumpToDownloadTask；原有开关及默认值保留。
- 解析器列表下载不改变保存的选择，首页更新提示保留原“更新并选择”语义。单选只暂存，✓ 确认才保存；删除保留确认，内置不可删除。
