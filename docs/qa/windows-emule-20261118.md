# CaptainFlash Windows 1.2.0 RC1 电驴验证

- 用上游发布的 SHA-256 校验 aMule 3.2.0 Windows x64 便携包和源码归档。便携包包含本机引擎、控制 API、第三方声明和对应源码。控制 API 仅绑定回环地址。
- 用独立配置实际启动、认证、关闭和重启引擎。用 eD2k 全局与 Kad 各搜索一次，均有真实结果。应用界面一次全局搜索收到 166 条结果。通过 Qt 测试驱动打开搜索、切换两个页签、点中结果、确认下载、查看队列、暂停、取消并正常关闭窗口。
- 公共 P2P 实测下载到字节数据，暂停后关闭并重启引擎，核对已下载的 1,589,874 字节仍在队列。使用已联网的引擎下载官方开源测试文件 `eMule0.72a-Sources.zip`，完成 4,345,733 字节，SHA-256 与上游一致。测试期间未运行下载文件。
- 两次新建配置从应用地址框直贴上述文件链接均已入队。观察窗口内未完成，未将这两次计为应用历史端到端通过。历史记录的路径、文件大小、去重与记录删除行为由测试覆盖。
- Windows 全量 pytest 439 项通过。搜索页面使用现有主题，以离屏渲染检查页签、结果列表、字号和布局。便携程序在独立配置中检查启动，窗口自动化在 Qt 离屏环境运行。
- Windows 候选包供试用。待复验项目为另一台 Windows 电脑的安装包启动，以及冷启动从链接到历史的完整链路。

上游测试文件见 [eMule 0.72a 发布页](https://github.com/irwir/eMule/releases/tag/eMule_v0.72a-community)。
